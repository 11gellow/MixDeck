## 问题与验证缺口

- 未执行：真实系统默认输出切换、物理拔插、Windows 10、高 DPI/最小窗口尺寸、系统注销/重启、长期资源与积压、安装打包。设备事件及注销分支有自动化测试，不能替代上述实机检查。
- Windows 音量混合器已作主音量与测试会话对照，未从混合器拖动写入；外部进程写入触发 UI 自动更新已实测。API 标量不等于最终听感，旧混合器的应用滑块显示也不能直接等同独立会话百分比。
- 托盘菜单显示/退出及释放由组件测试验证；通知区域双击恢复由用户协助验证。最小化隐藏沿用关闭隐藏的生命周期分支，尚未单独完成实际最小化操作；长期托盘稳定性留 S6-08。
- 本软件写入回传的 1 秒过滤窗口为界面层经验值；若系统回传积压超过 1 秒，滑块可能短暂回跳后再恢复。
- 规则优先级、稳定应用/设备匹配、配置路径及迁移策略仍需在对应任务前细化。
