## 辅助进程、恢复及复验方法

新增测试专用模式（无需安装，不进入产品界面）：

```powershell
dotnet tests/AudioManager.Tests/bin/Debug/net10.0-windows/AudioManager.Tests.dll --desktop-audio-fixture
```

它在默认输出创建同进程两个独立 GUID 的无声会话；启动时保存所有可用输出的主音量/静音及自身会话初值，将设备、会话键和回读值以 JSON 输出。需保持交互标准输入打开；普通非交互运行可能立即读到 EOF 并恢复退出。

1. 保持 Desktop 运行，启动辅助模式，观察两行自动出现，按辅助进程 PID 确认目标后操作。
2. 输入 `status` 回读全部可用设备主音量及自身会话；`external` 将第一个测试会话设为 0.23，用于观察外部事件；`restore` 恢复保存值并输出回读。
3. 输入 `stop` 或正常 EOF 后在 finally 中恢复并输出 `RESTORED`，随后释放无声会话。不要强制结束辅助进程；强制终止不能保证执行恢复逻辑。

本轮实机辅助 PID 为 46656，初始两个测试会话均 1.0/false；耳机主音量 0.16/false，扬声器 1.0/true。界面写入后通过独立进程逐项回读，随后执行恢复，最终 `stop` 输出 `RESTORED`、退出码 0。应用会话写入仅针对测试创建实例，未修改用户自有应用会话。完整回归之后再次确认没有 Desktop 或音频辅助进程残留；回归 TRX 中主音量恢复记录见上文。
