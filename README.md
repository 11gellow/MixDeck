# MixDeck v0.1.1

一个 Windows 音量管理工具，可以分别调节应用音量，并自动保存和恢复设置。

支持输出设备切换、托盘运行，以及浅色／深色主题。

v0.1.1 优化了登录自启动，音频设置更早生效。

## 下载

- [安装版（推荐）](https://github.com/11gellow/MixDeck/releases/download/v0.1.1/AudioManager-Setup.exe)：按向导安装即可。
- [便携版](https://github.com/11gellow/MixDeck/releases/download/v0.1.1/AudioManager-Portable.zip)：完整解压后运行，无需安装。

两个版本均适用于 Windows x64，无需另外安装 .NET。

目前主要在 Windows 11 上测试，遇到问题欢迎[提交 Issue](https://github.com/11gellow/MixDeck/issues)。
